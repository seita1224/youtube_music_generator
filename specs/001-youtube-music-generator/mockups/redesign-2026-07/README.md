# 再設計モック (2026-07)

枠(Slot)中心モデル(ADR-0041〜0050)の画面モック。ブラウザで直接開ける自己完結 HTML(外部依存なし)。

| ファイル | 内容 |
|---|---|
| `slot-centric-mock.html` | 主モック。編成表(ホーム)/ 枠詳細 / 枠詳細(公開済み)/ タイムライン / ジャンル / 分析 / プロンプト / 設定 |
| `design-alternatives.html` | 画面構成の検討過程。3 つの方向性を比較したもの。検討記録として凍結 |

## 位置づけ

**設計の正本は ADR**(`../../adr/0041`〜`0050`)。モックと ADR が矛盾する場合は ADR が正。

## ADR の反映状況

主モックは ADR-0041〜0050 を反映済み。対応は次のとおり。

| ADR | 画面上の表れ |
|---|---|
| 0041 枠が集約ルート | 編成表 → 枠詳細のブレイクダウン、公開枠パターンの編集、1 日複数枠、GPU は公開予定の早い順 |
| 0042 承認は公開ゲート 1 点 | 枠詳細の「公開待ち」工程の中だけに承認/却下がある |
| 0043 自動運転レベル | 設定でレベル未達なら選択不可 + 達成状況(7/10 枠)、降格は無条件、取り下げ導線 |
| 0044 停止手段 | 設定の「システムの状態」— 状態表示のみ、停止は CLI/Slack、compliance 自動停止、07:30 サマリ |
| 0045 状態機械 | 編成表の状態別表示と凡例、承認期限 7 日、遅延公開、失敗した枠、承認済み(公開予約)と取消 |
| 0046 やり直しと無効化 | 各工程のやり直し文言が依存関係ベース、トラック差し替え時の再検査、やり直し履歴 |
| 0047 目的関数 | 分析トップの目的カード、維持率の下限ライン、「暫定」表記、おまかせ選択の理由表示 |
| 0048 コメント | 分析と公開済み枠詳細の「視聴者の声」(読み取りのみと明示) |
| 0049 保持ポリシー | 公開済み枠の保持状況、旧世代 7 日、見送り 30 日の表示 |
| 0050 移行 | 認証画面はモック対象外(ADR-0013 のセッション認証を継承) |

## 対象外

- ログイン画面(認証は継承するがモックには含めない)
- 過去週・未来週の表示、公開済み以外の枠詳細の中身、監査ログ一覧、各種フォームの中身
- 動作するのは画面遷移と公開ゲートの状態変化(承認 / 取消 / 却下)、自動運転レベルの解錠判定のみ。他のボタンは説明トーストを出す
