# ADR-0015: 動画ビジュアライザ = SDXL 生成サムネ + ffmpeg `showwaves` overlay

- **ステータス:** Accepted
- **日付:** 2026-05-25
- **決定者:** @seita
- **タグ:** ml, ops, video

## 背景

要件「波形ビジュアライザ + 固定サムネ画像で構成する静止画ベース動画」の具体実装。
30分動画(ADR-0003)× 1日1〜2本(ADR-0004)を毎日生成するので、見栄え・生成負荷・長尺視聴の疲れにくさのバランスが必要。

ffmpeg のオーディオビジュアライザ候補:

- `showwaves`(波形)— 軽量、控えめな動き、長尺向き
- `showfreqs`(周波数バー)— 派手、EDM 系と相性良いが30分は疲れる
- `showspectrum`(スペクトログラム)— 情報量多いが地味になりがち
- `avectorscope`(ベクタースコープ)— アート寄り、玄人向け
- 完全静止画 — 最軽量だがエンゲージメント低下リスク

## 決定

- **背景: SDXL で生成した固定サムネ画像**(ADR-0009 で別途決めるサムネ生成方針に従う、本 ADR の対象外)
- **前景: `showwaves` 波形 overlay**(半透明、画面下部または中央に配置)
- ffmpeg のパイプライン例(概略):

  ```bash
  ffmpeg -loop 1 -i thumbnail.png -i audio.mp3 \
    -filter_complex "[1:a]showwaves=s=1920x300:mode=cline:colors=white@0.7[wave]; \
                     [0:v][wave]overlay=0:H-h[v]" \
    -map "[v]" -map 1:a -c:v libx264 -c:a aac -shortest output.mp4
  ```

- パラメータは設定可能とし、ジャンルごとに色・配置・モードを変える余地を残す
- 出力フォーマット: H.264 (libx264) + AAC、YouTube 推奨設定に合わせる
  - 解像度: 1920x1080(1080p)
  - フレームレート: 30fps(静止画ベースなので低 fps でも可、互換性で 30 採用)

## 結果

### 良い影響

- 完全静止画より視覚的エンゲージメントが上がる
- 派手なエフェクトと違い、30分長尺でも疲れにくい
- SDXL 生成サムネを背景に置けるため「作り込み感」が出せる
- ffmpeg 単体で完結、追加ランタイム不要

### 悪い影響・トレードオフ

- レンダリング時間が静止画のみより増える(30分動画で 3〜5分の処理)
  - 影響軽微: 1日1〜2本の規模なら問題なし
- ファイルサイズが静止画のみより増える(30分で 100〜200MB)
  - 緩和: 投稿後にローカル削除運用(../requirements.md §ストレージ)

### 受容したリスク

- ジャンルによっては波形 overlay が雰囲気に合わない可能性 → ジャンル別設定で吸収

## 検討した代替案

- **`showwaves` のみ(背景なし):** シンプルだが見栄えが弱い、SDXL サムネを生かせない。不採用。
- **`showfreqs` / `showspectrum`:** 動きが派手、30分視聴で疲労感が出やすい。不採用。
- **完全静止画:** 最軽量だが視聴維持率・エンゲージメントが落ちる可能性。不採用。
- **Remotion / Three.js などで別途レンダリング:** 追加ランタイム + 開発コスト。本要件には過剰。不採用。
