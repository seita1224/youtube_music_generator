# ADR-0004: 投稿規模は 1日1〜2本 から段階的に拡大

- **ステータス:** Accepted
- **日付:** 2026-05-25
- **決定者:** @seita
- **タグ:** ops, policy

## 背景

当初要件は「1チャンネルに全ジャンル混在 × 1日6本」だったが、グリル(Q3)で以下が判明:

- YouTube は **mass-produced / repetitious content** ポリシーで AI生成大量投稿チャンネルを停止対象としている(2024-09 更新)
- 1チャンネルに 1日6本 × 全ジャンル混在 × 毎日 は完全に該当パターン
- BAN 発生時、投稿済み動画・観察データ・収益化資格を **全て同時に失う**(動機 B + C の両方が消える)
- YouTube Data API daily quota = 10,000 units、`videos.insert` = 1,600 units/本 → 6本で 9,600 units(quota 枯渇すれすれ)

## 決定

- **MVP の投稿規模 = 1日1〜2本**(1〜2ジャンル × 各1動画 = 各30分)
- 1か月程度の運用で以下を観測してから段階拡大:
  - チャンネル停止・警告の有無
  - Content ID マッチ率(AcoustID プレチェックの漏れ率)
  - 視聴維持率・watch time の傾向
- 拡大判断は **改善計画 LLM ではなく人間判断**(動機 B + C の資産保護のため)
- 拡大シナリオ案(暫定):
  - フェーズ1(1か月): 1日1〜2本、単一チャンネル
  - フェーズ2(2〜3か月): 1日3〜4本、必要なら **ジャンル別チャンネル分散** で BAN リスク分散
  - フェーズ3(以降): 実績次第

## 結果

### 良い影響

- BAN リスクを最小化、観察データとマネタイズ資産を保護
- YouTube API quota に大幅な余裕
- 初期の品質チューニングコストが小さい

### 悪い影響・トレードオフ

- マネタイズ立ち上がりは遅い(動機 C の達成まで時間がかかる)
- 観察データの蓄積速度も落ちる(動機 B にもネガティブ)
  - 緩和: 1か月後に段階拡大判断を入れることで補う

### 受容したリスク

- 規模を絞っても AI生成チャンネルへの取締りで停止される可能性はゼロにはならない
- 拡大判断の運用ルールが未確定 → 1か月後に別 ADR で固める

## 検討した代替案

- **要件通り1日6本維持:** BAN リスク高、資産同時喪失のシナリオを受容できない。不採用。
- **当面投稿しない(動画ファイルのみ生成):** マネタイズ・観察データが永遠にゼロ。不採用。
- **ジャンル別チャンネル分散から開始:** 初期から複数チャンネルは運用負荷が高い。フェーズ2で検討。
